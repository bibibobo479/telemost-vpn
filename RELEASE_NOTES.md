# v0.1.0-beta.3 — Android без браузерных страниц

Telemost подключается через встроенный клиент без браузера, в том числе если
в старой версии был выключен режим headless. На главном экране отображаются
«Подключение…», «Подключено» или «Не подключено». Технические этапы остаются
в отдельной вкладке логов; ошибки, требующие внимания, остаются видимыми.
Для русского языка добавлены подписи основных статусов, кнопки и вкладок.

Установите APK поверх beta.2: код подключения и настройки сохранятся.
Повторная настройка сервера не нужна. Исправление получения комнаты из beta.2
сохранено. Ядро передачи данных не менялось.

Windows EXE — прежняя beta.2, Linux-архив — прежняя beta.1.

Это **бета-тест**. Скорость ориентировочно составляет **1/10 от скорости без
подключения**, без гарантии для конкретной сети.
Основа: [kulikov0/whitelist-bypass](https://github.com/kulikov0/whitelist-bypass).
Исходники под MIT, лицензии компонентов сохранены отдельно.

Проверки: сборка APK, подпись тем же ключом, Android instrumentation-тесты
простых состояний интерфейса, обработки кодов и переадресаций Диска.
Полный VPN-сеанс на физическом ARM-телефоне в этом окружении не проверен.
