# v0.1.0-beta.2 — исправление получения комнаты

Android и Windows теперь обрабатывают переадресации Яндекс Диска на сервер хранения.
Раньше ответ HTTP 302 приводил к ошибке «комната недоступна», даже когда сервер
и код подключения работали. OAuth-токен передаётся только API Диска.

Android показывает конкретные причины ошибки получения комнаты вместо общего
сообщения: DNS, тайм-аут, отказ токена, отсутствие файла и HTTP-ошибки.

Установите APK поверх предыдущей версии: подпись прежняя, настройки сохраняются.
Настраивать сервер заново не требуется. Windows EXE тоже обновлён; Linux-архив
совпадает с beta.1.

Проверено:

- 7 Android instrumentation-тестов, включая реальное получение актуальной комнаты
  с Яндекс Диска в временном эмуляторе Android API 37;
- разрешённые переадресации, отказ при небезопасных адресах, ограничение циклов
  и запрет переадресации запросов с OAuth;
- 3 теста Windows-клиента и компиляция TypeScript;
- подписанная сборка APK с увеличенным versionCode и проверкой сертификата;
- упаковка Windows x64 EXE.

Полный VPN-сеанс на физическом ARM-телефоне и Windows в этом окружении не проверен.

Это **бета-тест**. Ориентир скорости — **примерно 1/10 от скорости без подключения**,
без гарантии для конкретной сети. Настройка VPS и автоподбор пока доступны на Linux.
Одна серверная сессия рассчитана на одно активное клиентское подключение.

Основа: [kulikov0/whitelist-bypass](https://github.com/kulikov0/whitelist-bypass)
0.5.1 с исправлением фрагментации KCP. Исходники под MIT, лицензии компонентов
сохранены отдельно.

Windows EXE не подписан сертификатом издателя. SHA-256 сертификата Android:
`1b6cb0bd2680aa5bcd0e70afef9bf895a3b23bb4f48c159ad61330c699e42fd0`.
Контрольные суммы файлов находятся в `SHA256SUMS.txt`.
