# v0.1.0-beta.1 — первый публичный бета-тест

Клиенты личного Telemost VPN для Linux, Windows x64 и Android ARM64/ARMv7.
Основа: [kulikov0/whitelist-bypass](https://github.com/kulikov0/whitelist-bypass)
0.5.1 с исправлением фрагментации KCP.

- Linux: мастер настройки VPS, повторное использование уже настроенного сервера,
  код подключения, метрики, настройки и автоподбор по скорости.
- Windows/Android: импорт кода Linux-приложения, получение актуальной комнаты,
  VPN-подключение, логи и ручные параметры транспорта.
- Коды сохраняются через Windows safeStorage и Android Keystore.
- Windows: корректное отключение backend через QUIT для очистки собственных маршрутов.

**Оценка скорости — примерно 1/10 от скорости без туннеля.** Это ориентир по
наблюдениям, а не гарантия. Бета может работать нестабильно.

Проверено при сборке:

- тесты Go для исправления KCP;
- 17 тестов Linux-приложения;
- 2 теста обработки кодов Windows-клиента и компиляция TypeScript;
- сборка ядра Windows x64 и упаковка EXE с Wintun;
- подписанная release-сборка APK, проверка подписи и наличия обновлённых ARM-ядер;
- 3 Android instrumentation-теста в временном эмуляторе Android API 37 x86-64:
  идентификатор приложения, импорт/шифрование кода, отказ при повреждённом коде;
- установка и запуск Android-интерфейса в эмуляторе;
- контрольные суммы файлов Linux-архива и проверка исходников на секреты.

Не проверено в этом окружении: полный сетевой VPN-сеанс на реальной Windows с
Wintun и на физическом ARM-телефоне, скорость мобильной версии. Сборка и тесты
импорта не доказывают работоспособность туннеля во всех сетях.

Настройка нового VPS и автоподбор пока только на Linux. Код рассчитан на одну
серверную сессию: перед подключением другого устройства отключите первое.
На Android нельзя одновременно включить два системных VPN.

Windows EXE не подписан сертификатом издателя. Android APK подписан отдельным
ключом беты. SHA-256 сертификата Android:
`1b6cb0bd2680aa5bcd0e70afef9bf895a3b23bb4f48c159ad61330c699e42fd0`.

`SHA256SUMS.txt` содержит контрольные суммы загружаемых файлов. Исходники под MIT;
лицензии сторонних компонентов сохранены отдельно. Пароли и токены не публикуются.
