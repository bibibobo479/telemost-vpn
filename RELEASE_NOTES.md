# v0.1.0-beta.4 — возврат Android к поведению beta.2

Отменены изменения Android из beta.3: принудительное подключение Telemost без
браузера и изменения главного экрана. Восстановлены выбор режима подключения
и интерфейс beta.2. Исправление переадресаций Яндекс Диска сохранено.
Ядро передачи данных совпадает с beta.2.

APK подписан прежним ключом, versionCode увеличен: установите поверх beta.3,
не удаляя приложение. Код подключения и настройки сохраняются.
Windows EXE — beta.2, Linux-архив — beta.1, без изменений.

Это **бета-тест**. Ориентир скорости — **примерно 1/10 от скорости без подключения**,
без гарантии для конкретной сети. Основа:
[kulikov0/whitelist-bypass](https://github.com/kulikov0/whitelist-bypass).
Исходники под MIT; лицензии сторонних компонентов сохранены отдельно.

Проверки: сборка APK, подпись прежним ключом, совпадение Android-исходников и
встроенных ARM-ядер с beta.2 (кроме номера версии). Полный сеанс на физическом
телефоне в этом окружении не проверен.
