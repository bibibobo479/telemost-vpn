# Телемост VPN — Linux x86‑64

1. Распакуйте архив и запустите `bash install.sh`. Понадобится пароль администратора
   этого компьютера для установки зависимостей, приложения и сетевой службы.
2. Откройте **Телемост VPN** в меню приложений. При первом запуске откроется мастер.
3. Введите IP вашего VPS, порт SSH (обычно 22) и пароль root. Поддерживаются
   Ubuntu/Debian x86‑64 с systemd и Python 3; серверу нужен доступ к Яндексу.
   Если сервер уже настроен, нажмите **Использовать этот сервер**: повторная установка
   и вход в Яндекс не нужны.
4. Нажмите **Получить токен**, разрешите чтение и запись Яндекс Диска, вставьте токен.
   Если общее OAuth-приложение недоступно, мастер содержит кнопку регистрации своего
   приложения и инструкции по Client ID. Client Secret вводить не требуется.
5. Нажмите **Открыть вход в Яндекс**, войдите в отдельном окне Chrome/Chromium,
   затем нажмите **Я вошёл — получить cookies**. Можно импортировать JSON cookies из Creator.
6. Нажмите **Настроить сервер автоматически**. После создания комнаты — **Подключиться**.

На вкладке **Настройки** доступны FPS, batch и второй видеоканал. При сохранении
активное соединение будет перезапущено; параметры передаются серверу автоматически.
Автоподбор сравнивает профили по скорости и повторно измеряет победителя. Ошибки
передачи отображаются, но не исключают профиль и не обнуляют его скорость. Если
скорость измерить не удалось, прежний профиль сохраняется.
Остановка теста сохраняет прежние настройки. Автоподбор
временно отключает только Телемост VPN, оставляет обычные маршруты компьютера и
восстанавливает прежнее состояние подключения после завершения.

Пароль root используется только в процессе SSH-установки. Приложение запоминает
SSH-ключ сервера; при его изменении подключение блокируется. Токен Диска хранится
в закрытом каталоге `/etc/wb-vpn`, cookies — на VPS в `/var/lib/wb-telemost`.
Отдельный профиль браузера входа хранится в `~/.config/wb-telemost/browser-login`.
Архив приложения не содержит паролей, токенов, cookies или адреса конкретного VPS.

Чтобы перенести подключение на другой компьютер, в **Настройки → Поделиться
подключением** создайте и скопируйте код. На другом компьютере установите приложение,
вставьте код в мастере и нажмите **Подключить по коду**, затем **Подключиться**.
Пароль SSH и cookies не нужны. Код содержит секретный токен Диска; передавайте его
только доверенному человеку. Код не зашифрован и не ограничивает права токена.

Одна настройка рассчитана на одну серверную сессию. Перед подключением другого
компьютера отключите первый. Для двух одновременных устройств нужны отдельные сессии.

Закрытие приложения оставляет VPN включённым. Для отключения нажмите **Отключить**.
Службы Amnezia и её настройки установщик и автоподбор не изменяют.
