## Что это

Приложение для личного VPN-соединения через Яндекс Телемост между устройством
и собственным Linux-сервером. Оно упрощает развёртывание сервера, получение комнаты
и подключение устройств: вместо ручного ввода ссылки на каждую комнату используется
код подключения, а актуальная ссылка загружается через Яндекс Диск.

**Это экспериментальная бета-версия, а не стабильный VPN-сервис.** Возможны ошибки,
обрывы соединения и несовместимость с отдельными сетями и устройствами.

## Скорость

Ориентир по пользовательским наблюдениям: **скорость через туннель получается
приблизительно в 10 раз ниже — около одной десятой скорости без подключения**.
Это приблизительная оценка, а не гарантия и не универсальный результат измерений.
Скорость зависит от мобильной/домашней сети, маршрута до VPS, ограничений Телемоста,
FPS, batch и числа видеоканалов. Например, 50 Мбит/с напрямую могут дать около
5 Мбит/с через туннель; фактический результат может заметно отличаться.

## Первый сервер

1. На Linux распакуйте архив и выполните `bash install.sh`.
2. Откройте «Телемост VPN» и введите IP VPS, SSH-порт и пароль root.
3. Если служба уже установлена, выберите «Использовать этот сервер»: повторная
   установка не выполняется.
4. Для нового сервера мастер предложит получить OAuth-токен Яндекс Диска и войти
   в Телемост в отдельном окне Chrome/Chromium. Затем служба устанавливается автоматически.
5. Нажмите «Подключиться». В настройках создайте код для другого устройства.

Для VPS нужны Ubuntu/Debian x86-64, systemd, Python 3, root SSH и доступ к Яндексу.
Подробности: [инструкция Linux](linux/QUICKSTART.md).

## Windows

Скачайте EXE из Releases и запустите с правами администратора для Wintun.
Вставьте код `TMVPN1.…` в поле кода, нажмите «Импортировать код», затем `Start`.
Не заменяйте служебное значение `telemost-share://default` ссылкой на старую комнату:
оно включает автоматическое обнаружение комнаты. `Stop` отключает туннель.
Для режима локального прокси предусмотрен `SOCKS5 only`.

EXE не подписан сертификатом издателя Windows. Это переносимое приложение;
системный VPN требует административных прав. Токен сохраняется зашифрованным
через системное хранилище Electron/Windows и не включается в журнал.

## Android

Установите APK из Releases (Android 6.0+, ARM64/ARMv7). В списке подключений нажмите
добавление, вставьте код `TMVPN1.…` в поле ссылки, сохраните и нажмите подключение.
Разрешите создание системного VPN в диалоге Android. Перед каждой новой попыткой
подключения приложение получает актуальную комнату с Диска.

Код хранится с AES-GCM и ключом Android Keystore, резервное копирование данных
приложения отключено. APK подписан отдельным ключом этой беты; ключ не публикуется.
Android разрешает один активный системный VPN: одновременная работа двух VPN
приложений не поддерживается платформой. Клиент не управляет настройками Amnezia.

## Параметры и ограничения

- Базовый профиль: 60 FPS, batch 120, один видеоканал, KCP.
- Dual-track означает два видеоканала **одного** соединения.
- Одна серверная сессия предназначена для одного активного клиента. Перед
  подключением другого устройства отключите первое. Для одновременной работы
  двух клиентов нужны отдельные серверные сессии.
- Linux-автоподбор сравнивает измеренную скорость. Ошибки передачи видны в отчёте,
  но не исключают профиль; самый быстрый профиль может быть нестабильным.
- Код подключения содержит OAuth-токен Диска. Это секрет, а не публичная ссылка.
  Упаковка кода не является шифрованием и не сужает права токена. Передавайте код
  только доверенным людям. SSH-пароль и cookies в код не входят.
- Пароли, cookies, OAuth-токены, персональные адреса серверов и ключи подписи
  не входят в исходники и готовые сборки.

## Сборка и проверка

См. [BUILDING.md](BUILDING.md). Ядро фиксировано на Go 1.26.1 из-за совместимости
зависимости headless-client. Исправлена фрагментация KCP: полезная нагрузка TCP
учитывает заголовки KCP и relay, уменьшая лишнее разбиение пакетов.

Бета-сборка не означает подтверждённую работу на всех Windows/Android-устройствах.
Объём реально выполненных проверок указан в заметках к релизу. Сообщая об ошибке,
укажите ОС и версию приложения, тип сети, профиль и шаги воспроизведения;
не прикладывайте код подключения, токены, cookies и пароли.
